# canopy-b flora (authored)

Generated by `Tools/Author-Flora-canopy_b.py` (headless Blender 5.2). Deterministic: the same seed and parameters reproduce the same geometry.

Species (FloraCatalog canopy-b and subcanopy): acacia_flat, baldcypress, cottonwood_river, emergent_fig (canopy-b, LOD0 20k-80k); birch_pale, understory_laurel (subcanopy, LOD0 10k-40k). Three variants each (size, shape, colour).

Conventions: metres. Blender scene is Z-up. GLB is Y-up (glTF spec). FBX is Blender-native Z-up (identity axes). Origin at ground centre (min Z = 0, trunk base on XY origin).

Vertex colour `WindWeight` (COLOR_0 in GLB): R = wind weight, 0 at trunk base to 1 at tips and leaves (leaves 0.7 to 1.0). G = B = 0, A = 1.

Material slots: `Bark` (opaque, baked tint + normal map). `Leaves` (alpha-masked, two-sided, leaf-cluster cards). Alpha mode MASK, cutoff 0.5.

LOD1 = Decimate collapse, ratio 0.30 of LOD0. LOD2 = Decimate collapse, ratio 0.08 of LOD0. Each LOD is a separate file, GLB and FBX.
