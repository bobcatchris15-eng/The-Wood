# conifer flora (authored)

Generated by `Tools/Author-Flora-conifer.py` (headless Blender 5.2). Deterministic: the same seed and parameters reproduce the same geometry.

Species (FloraCatalog): pine_open, spruce_conifer, larch_sparse, krummholz_pine. Three variants each (different branch layouts per variant; krummholz: low, wind-flagged to +X).

Structure: real branch hierarchy, foliage always attached. spruce/larch = whorls of drooping primary branches carrying overlapping needle fronds (3 planes) plus hanging curtains between whorls. pine = bare bole, upswept limbs, secondaries, twigs; needle plumes run along the outer third of each limb and along the twigs. krummholz = contorted trunk, limbs and foliage on the lee side only.

Conventions: metres. Blender scene is Z-up. GLB is Y-up (glTF spec). FBX is Blender-native Z-up. Origin at ground centre (min Z = 0, trunk base on XY origin).

Vertex colour `WindWeight` (COLOR_0 in GLB): R = wind weight, 0 at trunk base to 1 at tips (needles 0.7 to 1.0). G = B = 0, A = 1.

Material slots: `Bark` (opaque, tinted, normal map). `Leaves` (alpha-masked, two-sided). Alpha mode MASK, cutoff 0.5.

LOD1 / LOD2 = regrown at ~30% / ~8% of the LOD0 triangle count (lower card density, simpler wood), then merge-by-distance and degenerate-face clean. Decimate collapse is not used: on disjoint cards it erodes them. Each LOD is a separate GLB and FBX.

Previews: `<name>_preview.png` 3/4 view with ground plane; `<name>_far.png` 30 m, eye height 1.7 m, level camera (silhouette check). Cov = opaque fraction inside the convex hull of the crown in an orthographic side view (spruce >= 0.75, pine >= 0.45 required).

## Provenance

- Geometry: procedural, generated by `Tools/Author-Flora-conifer.py`. No third-party meshes.
- Pine needle plume: Poly Haven pine_tree_01 twig alpha + diffuse (CC0), `ArtSource/PolyHaven/pine_tree_01/textures/`. One spray is gated, cropped and resampled to a 512x1024 card texture, lines thickened slightly.
- Spruce / larch fronds: drawn procedurally (herringbone twigs, needles as line strokes). Needle colours are sampled from Poly Haven fir_tree_01 twig diffuse (CC0); that sheet has no alpha mask, so the mask is drawn.
- Bark colour and normal: Poly Haven pine_tree_01 or fir_tree_01 bark (CC0). Read in place, baked tint into `<name>_bark.png`.
- Poly Haven CC0 status per site licence. Not individually re-verified in this run.
